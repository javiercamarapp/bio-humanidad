# Prompt — Analista (modelo frontera)

Rol: explicar anomalías con evidencia. Corre pocas veces por semana. Es el único paso caro.

```
Te doy N señales de esta semana y la línea base de los últimos 90 días.
1. Nombra las 3 más anómalas contra esa línea base.
2. Para cada una: qué patrón rompe, qué explicación benigna tiene,
   y qué evidencia la confirmaría o la MATARÍA.
3. Si nada es anómalo, responde solo "sin anomalía" y explica por qué.
No especules sobre patógenos ni sobre cómo fabricar nada.
Trabaja solo con señales observables. Cita la url de cada afirmación.
```
